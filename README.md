# SLCC Hub (Smart Life Care Center Hub)

**SLCC Hub** เป็นระบบบริหารจัดการศูนย์พักพิงและทรัพยากรแบบครบวงจร (Integrated Shelter and Resource Management System) ที่ออกแบบมาเพื่อรองรับการดำเนินงานในสถานการณ์ฉุกเฉินหรือภัยพิบัติ เพื่อให้การกระจายความช่วยเหลือเป็นไปอย่างมีประสิทธิภาพและทั่วถึง

## 🎯 หน้าที่และการทำงานของโปรเจ็กต์
ระบบนี้ทำหน้าที่เป็นศูนย์กลางข้อมูล (Centralized Data Hub) สำหรับ:
*   **การจัดการศูนย์พักพิง (Shelter Management):** ติดตามสถานะความจุ (Capacity) และจำนวนผู้อาศัยจริง (Occupancy) ของศูนย์พักพิงแต่ละแห่งแบบ Real-time
*   **การจัดการทรัพยากร (Resource Management):** ควบคุมและกระจายสิ่งของบรรเทาทุกข์ไปยังจุดต่างๆ ที่มีความจำเป็น
*   **การวิเคราะห์ข้อมูล (Data Visualization):** แสดงผลสถิติและสถานะวิกฤตผ่าน Dashboard และแผนที่ เพื่อช่วยในการตัดสินใจเชิงกลยุทธ์

## 📦 ฟีเจอร์สำคัญด้านการบริหารจัดการสต็อกสินค้า
ระบบสต็อกสินค้าใน SLCC Hub ถูกออกแบบมาเพื่อความแม่นยำและการตรวจสอบได้ (Accountability):
*   **Inventory Categorization:** แยกหมวดหมู่สิ่งของชัดเจน (เช่น อาหาร, ยา, เครื่องนุ่งห่ม, อุปกรณ์เครื่องนอน)
*   **Real-time Stock Tracking:** บันทึกรับเข้า-เบิกจ่ายสินค้า พร้อมปรับยอดคงคลังอัตโนมัติ
*   **Expiry & Quality Control:** ฟิลด์บันทึกวันหมดอายุและบันทึกหมายเหตุสำหรับสินค้าแต่ละล็อต
*   **Multi-location Inventory:** รองรับการจัดการสต็อกแยกตามศูนย์พักพิงหรือคลังส่วนกลาง
*   **Resource Request System:** ระบบจับคู่ (Matching) ระหว่างความต้องการของศูนย์พักพิงกับทรัพยากรที่มีอยู่ในคลัง
*   **Data Import/Export:** รองรับการนำเข้าและส่งออกข้อมูลสต็อกผ่านไฟล์ Excel เพื่อความสะดวกในการวิเคราะห์และรายงานผล

## 👥 สิทธิ์ผู้ใช้งานและหน้าที่ความรับผิดชอบ
ระบบมีการแบ่งสิทธิ์ผู้ใช้งานออกเป็น 3 ระดับหลัก เพื่อความปลอดภัยและความเป็นสัดส่วนในการจัดการข้อมูล:

### 1. ผู้ดูแลระบบ (Admin)
*   **การจัดการภาพรวม:** มีสิทธิ์เข้าถึงทุกส่วนของระบบ รวมถึงการจัดการผู้ใช้งาน (User Management) และการจัดการศูนย์กลาง (Hub Management)
*   **การบริหารสต็อก:** สามารถเพิ่ม แก้ไข ลบ และนำเข้า/ส่งออกทรัพยากรทั้งหมดในระบบ รวมถึงการโอนย้ายทรัพยากรระหว่างศูนย์

### 2. เจ้าหน้าที่ (Staff)
*   **การดำเนินงานประจำวัน:** จัดการข้อมูลการเข้าพัก (Check-in/Check-out) และอัปเดตสถานะความจุของศูนย์พักพิง
*   **การจัดการสต็อก:** สามารถบันทึกการรับเข้าทรัพยากรใหม่ อัปเดตจำนวนสินค้าคงเหลือ และตรวจสอบรายการสิ่งของในคลังที่รับผิดชอบ

### 3. ผู้ใช้งานทั่วไป / ผู้ประสบภัย (User)
*   **การเข้าถึงข้อมูลสาธารณะ:** สามารถค้นหาและดูสถานะของศูนย์พักพิง (ว่าง/เต็ม) ตำแหน่งที่ตั้ง และข้อมูลการติดต่อผ่านหน้าหลัก
*   **ข้อจำกัด:** ไม่สามารถเข้าสู่ระบบหลังบ้านเพื่อแก้ไขข้อมูลใดๆ ได้

## 🏗️ สถาปัตยกรรมภาพรวมของโปรเจ็กต์ (Architecture Overview)
โปรเจ็กต์นี้พัฒนาขึ้นด้วยเทคโนโลยีสมัยใหม่ในรูปแบบ Full-stack Application:

*   **Frontend Ecosystem:** 
    *   **Next.js & React 19:** ใช้เป็นโครงสร้างหลักในการพัฒนา UI แบบ Component-based
    *   **Bootstrap 5:** สำหรับการออกแบบ Interface ที่สะอาดตาและรองรับการใช้งานผ่านมือถือ (Responsive Design)
    *   **Recharts:** สำหรับการสร้าง Chart และ Graph เพื่อสรุปยอดทรัพยากรและสถิติ
    *   **Leaflet:** ระบบแผนที่ปฏิสัมพันธ์สำหรับแสดงตำแหน่งและสถานะของศูนย์พักพิง
*   **Backend & API:**
    *   **Next.js API Routes:** จัดการ Logic ฝั่งเซิร์ฟเวอร์แบบ Serverless ใช้งานง่ายและมีความปลอดภัยสูง
    *   **NextAuth.js:** ระบบจัดการสิทธิ์การเข้าถึง (Authentication & Authorization) สำหรับ Admin และ Staff
*   **Database & Storage:**
    *   **MongoDB:** ฐานข้อมูล NoSQL ที่มีความยืดหยุ่นสูง เหมาะสำหรับการเก็บข้อมูลทรัพยากรที่มีความหลากหลาย
    *   **Mongoose ODM:** สำหรับการจัดการ Schema และการเชื่อมต่อฐานข้อมูลอย่างเป็นระบบ
*   **Development Tools:** พัฒนาด้วย **TypeScript** ตลอดทั้งโปรเจ็กต์เพื่อลดข้อผิดพลาดในการเขียนโปรแกรมและเพิ่มประสิทธิภาพในการบำรุงรักษาโค้ด
